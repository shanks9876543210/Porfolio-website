# Binay Rai — Portfolio

Personal portfolio website for Binay Rai, Backend Developer.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v3
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Cloudflare Pages

1. Push to GitHub
2. Connect repository on Cloudflare Pages
3. Build command: `npm run build`
4. Output directory: `dist`

## Configuration

- Update `src/data/portfolio.ts` with your real email
- Replace `YOUR_WEB3FORMS_KEY` in `src/components/Contact.tsx` with your Web3Forms access key from https://web3forms.com
- Update social links in `src/data/portfolio.ts`
